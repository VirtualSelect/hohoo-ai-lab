# A1：把一轮对话当作一次提交
Java 8 / Gson。候选请求构建、完整对话对剪裁、UTF-8请求字节上限、失败不提交。
消息上限和字节上限不是模型Token预算；不做摘要，不保证遗忘后还能回答旧事实。

```powershell
mvn -q compile
mvn -q exec:java "-Dexec.args=--self-test evidence/new-run.json"
# 自行配置 AGNES_API_KEY 后才可发出真实请求
mvn -q exec:java "-Dexec.args=--live"
```

正式离线记录：evidence/20260930-contract.json。所有模型回答与超时/429/解析失败均由显式测试替身提供，不是模型实测，也不是真实网络故障注入。HTTP适配器可用agnes-3.0-flash，但本目录本轮没有在线请求。无自动重试。

事务边界仅指单进程会话状态：校验当前输入 → 复制已提交历史 → 剪裁候选的完整对话对 → 发一次请求 → 验收非空且finish_reason=stop → 原子替换内存历史。失败连剪裁也不提交。不是数据库事务，不实现服务器幂等、崩溃恢复或分布式并发。synchronized串行化同一会话，网络等待期间占锁；不适合作为高并发服务的最终设计。请求返回“stop”只满足完整性条件，不证明回答事实正确。

响应正文上限256KiB。历史最多4个已提交对话对，候选请求最多16000 UTF-8字节（包含JSON转义、system、model）；超大当前问题本地拒绝。大回复可能保存在历史中，但下轮请求会按完整对话对清理。保留限额限制的是提交后的历史，当前请求可以是已有4对+当前问题。
